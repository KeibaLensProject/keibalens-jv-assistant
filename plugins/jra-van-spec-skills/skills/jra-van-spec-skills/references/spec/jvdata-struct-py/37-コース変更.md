# 106.コース変更 (Python)

出典: `context/JVData_Struct.py` (JRA-VAN提供サンプル, 最終更新 2026-07-31, SDK Ver.5.0.0)

| クラス (`@dataclass`) | 概要 |
|---|---|
| `CC_INFO` | 変更情報 |
| `JV_CC_INFO` | コース変更 |

```python
@dataclass
class CC_INFO:
    """変更情報"""
    Kyori: str      # 距離
    TruckCd: str    # トラックコード

    # データセット
    @classmethod
    def SetDataB(cls, b):
        return cls(
            MidB2S(b, 1, 4),
            MidB2S(b, 5, 2),
        )

@dataclass
class JV_CC_INFO:
    head: RECORD_ID         # <レコードヘッダー>
    id: RACE_ID             # <競走識別情報>
    HappyoTime: MDHM        # 発表月日時分
    CCInfoAfter: CC_INFO    # <変更後情報>
    CCInfoBefore: CC_INFO   # <変更前情報>
    JiyuCd: str             # 事由区分
    crlf: str               # レコード区切り

    # データセット
    @classmethod
    def SetDataB(cls, b):
        return cls(
            RECORD_ID.SetDataB(MidB2B(b, 1, 11)),
            RACE_ID.SetDataB(MidB2B(b, 12, 16)),
            MDHM.SetDataB(MidB2B(b, 28, 8)),
            CC_INFO.SetDataB(MidB2B(b, 36, 6)),
            CC_INFO.SetDataB(MidB2B(b, 42, 6)),
            MidB2S(b, 48, 1),
            MidB2S(b, 49, 2),
        )
```
