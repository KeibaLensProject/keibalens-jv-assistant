# 105.発走時刻変更 (Python)

出典: `context/JVData_Struct.py` (JRA-VAN提供サンプル, 最終更新 2026-07-31, SDK Ver.5.0.0)

| クラス (`@dataclass`) | 概要 |
|---|---|
| `TC_INFO` | 変更情報 |
| `JV_TC_INFO` | 発走時刻変更 |

```python
@dataclass
class TC_INFO:
    """変更情報"""
    Ji: str     # 時
    Fun: str    # 分

    # データセット
    @classmethod
    def SetDataB(cls, b):
        return cls(
            MidB2S(b, 1, 2),
            MidB2S(b, 3, 2),
        )

@dataclass
class JV_TC_INFO:
    head: RECORD_ID         # <レコードヘッダー>
    id: RACE_ID             # <競走識別情報>
    HappyoTime: MDHM        # 発表月日時分
    TCInfoAfter: TC_INFO    # <変更後情報>
    TCInfoBefore: TC_INFO   # <変更前情報>
    crlf: str               # レコード区切り

    # データセット
    @classmethod
    def SetDataB(cls, b):
        return cls(
            RECORD_ID.SetDataB(MidB2B(b, 1, 11)),
            RACE_ID.SetDataB(MidB2B(b, 12, 16)),
            MDHM.SetDataB(MidB2B(b, 28, 8)),
            TC_INFO.SetDataB(MidB2B(b, 36, 4)),
            TC_INFO.SetDataB(MidB2B(b, 40, 4)),
            MidB2S(b, 44, 2),
        )
```
