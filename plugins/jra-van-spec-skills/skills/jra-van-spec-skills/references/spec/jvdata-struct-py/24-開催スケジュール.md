# 25.開催スケジュール (Python)

出典: `context/JVData_Struct.py` (JRA-VAN提供サンプル, 最終更新 2026-07-31, SDK Ver.5.0.0)

| クラス (`@dataclass`) | 概要 |
|---|---|
| `JYUSYO_INFO` | 重賞案内 |
| `JV_YS_SCHEDULE` | 開催スケジュール |

```python
@dataclass
class JYUSYO_INFO:
    """重賞案内"""
    TokuNum: str        # 特別競走番号
    Hondai: str         # 競走名本題
    Ryakusyo10: str     # 競走名略称10字
    Ryakusyo6: str      # 競走名略称6字
    Ryakusyo3: str      # 競走名略称3字
    Nkai: str           # 重賞回次[第N回]
    GradeCD: str        # グレードコード
    SyubetuCD: str      # 競走種別コード
    KigoCD: str         # 競走記号コード
    JyuryoCD: str       # 重量種別コード
    Kyori: str          # 距離
    TrackCD: str        # トラックコード

    # データセット
    @classmethod
    def SetDataB(cls, b):
        return cls(
            MidB2S(b, 1, 4),
            MidB2S(b, 5, 60),
            MidB2S(b, 65, 20),
            MidB2S(b, 85, 12),
            MidB2S(b, 97, 6),
            MidB2S(b, 103, 3),
            MidB2S(b, 106, 1),
            MidB2S(b, 107, 2),
            MidB2S(b, 109, 3),
            MidB2S(b, 112, 1),
            MidB2S(b, 113, 4),
            MidB2S(b, 117, 2),
        )

@dataclass
class JV_YS_SCHEDULE:
    head: RECORD_ID                     # <レコードヘッダー>
    id: RACE_ID2                        # <競走識別情報２>
    YoubiCD: str                        # 曜日コード
    JyusyoInfo: List[JYUSYO_INFO]       # <重賞案内>
    crlf: str                           # レコード区切り

    # データセット
    @classmethod
    def SetDataB(cls, b):
        return cls(
            RECORD_ID.SetDataB(MidB2B(b, 1, 11)),
            RACE_ID2.SetDataB(MidB2B(b, 12, 14)),
            MidB2S(b, 26, 1),
            [JYUSYO_INFO.SetDataB(MidB2B(b, 27 + 118 * i, 118)) for i in range(3)],
            MidB2S(b, 381, 2),
        )
```
