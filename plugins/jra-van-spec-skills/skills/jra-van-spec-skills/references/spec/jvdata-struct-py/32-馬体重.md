# 101.馬体重 (Python)

出典: `context/JVData_Struct.py` (JRA-VAN提供サンプル, 最終更新 2026-07-31, SDK Ver.5.0.0)

| クラス (`@dataclass`) | 概要 |
|---|---|
| `BATAIJYU_INFO` | 馬体重情報 |
| `JV_WH_BATAIJYU` | 馬体重 |

```python
@dataclass
class BATAIJYU_INFO:
    """馬体重情報"""
    Umaban: str     # 馬番
    Bamei: str      # 馬名
    BaTaijyu: str   # 馬体重
    ZogenFugo: str  # 増減符号
    ZogenSa: str    # 増減差

    # データセット
    @classmethod
    def SetDataB(cls, b):
        return cls(
            MidB2S(b, 1, 2),
            MidB2S(b, 3, 36),
            MidB2S(b, 39, 3),
            MidB2S(b, 42, 1),
            MidB2S(b, 43, 3),
        )

@dataclass
class JV_WH_BATAIJYU:
    head: RECORD_ID                     # <レコードヘッダー>
    id: RACE_ID                         # <競走識別情報>
    HappyoTime: MDHM                    # 発表月日時分
    BataijyuInfo: List[BATAIJYU_INFO]   # <馬体重情報>
    crlf: str                           # レコード区切り

    # データセット
    @classmethod
    def SetDataB(cls, b):
        return cls(
            RECORD_ID.SetDataB(MidB2B(b, 1, 11)),
            RACE_ID.SetDataB(MidB2B(b, 12, 16)),
            MDHM.SetDataB(MidB2B(b, 28, 8)),
            [BATAIJYU_INFO.SetDataB(MidB2B(b, 36 + 45 * i, 45)) for i in range(18)],
            MidB2S(b, 846, 2),
        )
```
