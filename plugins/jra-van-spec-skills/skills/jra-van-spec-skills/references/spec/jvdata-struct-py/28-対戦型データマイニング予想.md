| クラス (`@dataclass`) | 概要 |
|---|---|
| `TM_INFO` | 対戦型データマイニング予想 |
| `JV_TM_INFO` | 対戦型データマイニング予想 |

```python
@dataclass
class TM_INFO:
    """対戦型データマイニング予想"""
    Umaban: str     # 馬番
    TMScore: str    # 予測スコア

    # データセット
    @classmethod
    def SetDataB(cls, b):
        return cls(
            MidB2S(b, 1, 2),
            MidB2S(b, 3, 4),
        )

@dataclass
class JV_TM_INFO:
    head: RECORD_ID         # <レコードヘッダー>
    id: RACE_ID             # <競走識別情報>
    MakeHM: HM              # データ作成時分
    TMInfo: List[TM_INFO]   # <マイニング予想>
    crlf: str               # レコード区切り

    # データセット
    @classmethod
    def SetDataB(cls, b):
        return cls(
            RECORD_ID.SetDataB(MidB2B(b, 1, 11)),
            RACE_ID.SetDataB(MidB2B(b, 12, 16)),
            HM.SetDataB(MidB2B(b, 28, 4)),
            [TM_INFO.SetDataB(MidB2B(b, 32 + 6 * i, 6)) for i in range(18)],
            MidB2S(b, 140, 2),
        )
```
