# 21.レコードマスタ (Python)

出典: `context/JVData_Struct.py` (JRA-VAN提供サンプル, 最終更新 2026-07-31, SDK Ver.5.0.0)

| クラス (`@dataclass`) | 概要 |
|---|---|
| `RECUMA_INFO` | レコード保持馬情報 |
| `JV_RC_RECORD` | レコードマスタ |

```python
@dataclass
class RECUMA_INFO:
    """レコード保持馬情報"""
    KettoNum: str       # 血統登録番号
    Bamei: str          # 馬名
    UmaKigoCD: str      # 馬記号コード
    SexCD: str          # 性別コード
    ChokyosiCode: str   # 調教師コード
    ChokyosiName: str   # 調教師名
    Futan: str          # 負担重量
    KisyuCode: str      # 騎手コード
    KisyuName: str      # 騎手名

    # データセット
    @classmethod
    def SetDataB(cls, b):
        return cls(
            MidB2S(b, 1 , 10),
            MidB2S(b, 11, 36),
            MidB2S(b, 47, 2),
            MidB2S(b, 49, 1),
            MidB2S(b, 50, 5),
            MidB2S(b, 55, 34),
            MidB2S(b, 89, 3),
            MidB2S(b, 92, 5),
            MidB2S(b, 97, 34),
        )

@dataclass
class JV_RC_RECORD:
    head: RECORD_ID                 # <レコードヘッダー>
    RecInfoKubun: str               # レコード識別区分
    id: RACE_ID                     # <競走識別情報>
    TokuNum: str                    # 特別競走番号
    Hondai: str                     # 競走名本題
    GradeCD: str                    # グレードコード
    SyubetuCD: str                  # 競走種別コード
    Kyori: str                      # 距離
    TrackCD: str                    # トラックコード
    RecKubun: str                   # レコード区分
    RecTime: str                    # レコードタイム
    TenkoBaba: TENKO_BABA_INFO      # 天候・馬場状態
    RecUmaInfo: List[RECUMA_INFO]   # <レコード保持馬情報>
    crlf: str                       # レコード区切り

    # データセット
    @classmethod
    def SetDataB(cls, b):
        return cls(
            RECORD_ID.SetDataB(MidB2B(b, 1, 11)),
            MidB2S(b, 12, 1),
            RACE_ID.SetDataB(MidB2B(b, 13, 16)),
            MidB2S(b, 29, 4),
            MidB2S(b, 33, 60),
            MidB2S(b, 93, 1),
            MidB2S(b, 94, 2),
            MidB2S(b, 96, 4),
            MidB2S(b, 100, 2),
            MidB2S(b, 102, 1),
            MidB2S(b, 103, 4),
            TENKO_BABA_INFO.SetDataB(MidB2B(b, 107, 3)),
            [RECUMA_INFO.SetDataB(MidB2B(b, 110 + 130 * i, 130)) for i in range(3)],
            MidB2S(b, 500, 2),
        )
```
