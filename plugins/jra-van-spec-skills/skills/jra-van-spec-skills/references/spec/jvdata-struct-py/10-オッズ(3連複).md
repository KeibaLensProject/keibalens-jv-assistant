# 11.オッズ(3連複) (Python)

出典: `context/JVData_Struct.py` (JRA-VAN提供サンプル, 最終更新 2026-07-31, SDK Ver.5.0.0)

| クラス (`@dataclass`) | 概要 |
|---|---|
| `ODDS_SANREN_INFO` | 3連複オッズ |
| `JV_O5_ODDS_SANREN` | オッズ(3連複) |

```python
@dataclass
class ODDS_SANREN_INFO:
    """3連複オッズ"""
    Kumi: str       # 組番
    Odds: str       # オッズ
    Ninki: str      # 人気順

    # データセット
    @classmethod
    def SetDataB(cls, b):
        return cls(
            MidB2S(b, 1, 6),
            MidB2S(b, 7, 6),
            MidB2S(b, 13, 3),
        )

@dataclass
class JV_O5_ODDS_SANREN:
    head: RECORD_ID                             # <レコードヘッダー>
    id: RACE_ID                                 # <競走識別情報>
    HappyoTime: MDHM                            # 発表月日時分
    TorokuTosu: str                             # 登録頭数
    SyussoTosu: str                             # 出走頭数
    SanrenpukuFlag: str                         # 発売フラグ 3連複
    OddsSanrenInfo: List[ODDS_SANREN_INFO]      # <3連複票数オッズ>
    TotalHyosuSanrenpuku: str                   # 3連複票数合計
    crlf: str                                   # レコード区切り

    # データセット
    @classmethod
    def SetDataB(cls, b):
        return cls(
            RECORD_ID.SetDataB(MidB2B(b, 1, 11)),
            RACE_ID.SetDataB(MidB2B(b, 12, 16)),
            MDHM.SetDataB(MidB2B(b, 28, 8)),
            MidB2S(b, 36, 2),
            MidB2S(b, 38, 2),
            MidB2S(b, 40, 1),
            [ODDS_SANREN_INFO.SetDataB(MidB2B(b, 41 + 15 * i, 15)) for i in range(816)],
            MidB2S(b, 12281, 11),
            MidB2S(b, 12292, 2),
        )
```
