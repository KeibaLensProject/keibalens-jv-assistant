# 28.タイム型データマイニング予想 (Python)

出典: `context/JVData_Struct.py` (JRA-VAN提供サンプル, 最終更新 2026-07-31, SDK Ver.5.0.0)

| クラス (`@dataclass`) | 概要 |
|---|---|
| `DM_INFO` | マイニング予想 |
| `JV_DM_INFO` | タイム型データマイニング予想 |

```python
@dataclass
class DM_INFO:
    """マイニング予想"""
    Umaban: str     # 馬番
    DMTime: str     # 予想走破タイム
    DMGosaP: str    # 予想誤差(信頼度)＋
    DMGosaM: str    # 予想誤差(信頼度)－

    # データセット
    @classmethod
    def SetDataB(cls, b):
        return cls(
            MidB2S(b, 1, 2),
            MidB2S(b, 3, 5),
            MidB2S(b, 8, 4),
            MidB2S(b, 12, 4),
        )

@dataclass
class JV_DM_INFO:
    head: RECORD_ID         # <レコードヘッダー>
    id: RACE_ID             # <競走識別情報>
    MakeHM: HM              # データ作成時分
    DMInfo: List[DM_INFO]   # <マイニング予想>
    crlf: str               # レコード区切り

    # データセット
    @classmethod
    def SetDataB(cls, b):
        return cls(
            RECORD_ID.SetDataB(MidB2B(b, 1, 11)),
            RACE_ID.SetDataB(MidB2B(b, 12, 16)),
            HM.SetDataB(MidB2B(b, 28, 4)),
            [DM_INFO.SetDataB(MidB2B(b, 32 + 15 * i, 15)) for i in range(18)],
            MidB2S(b, 302, 2),
        )
```
