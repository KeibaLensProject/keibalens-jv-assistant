| クラス (`@dataclass`) | 概要 |
|---|---|
| `ODDS_UMATAN_INFO` | 馬単オッズ |
| `JV_O4_ODDS_UMATAN` | オッズ(馬単) |

```python
@dataclass
class ODDS_UMATAN_INFO:
    """馬単オッズ"""
    Kumi: str       # 組番
    Odds: str       # オッズ
    Ninki: str      # 人気順

    # データセット
    @classmethod
    def SetDataB(cls, b):
        return cls(
            MidB2S(b, 1, 4),
            MidB2S(b, 5, 6),
            MidB2S(b, 11, 3),
        )

@dataclass
class JV_O4_ODDS_UMATAN:
    head: RECORD_ID                             # <レコードヘッダー>
    id: RACE_ID                                 # <競走識別情報>
    HappyoTime: MDHM                            # 発表月日時分
    TorokuTosu: str                             # 登録頭数
    SyussoTosu: str                             # 出走頭数
    UmatanFlag: str                             # 発売フラグ 馬単
    OddsUmatanInfo: List[ODDS_UMATAN_INFO]      # <馬単票数オッズ>
    TotalHyosuUmatan: str                       # 馬単票数合計
    crlf: str                                   # レコード区切り

    # データセット
    @classmethod
    def SetDataB(cls, b):
        return cls(
            RECORD_ID.SetDataB(MidB2B(b, 1, 11)),
            RACE_ID.SetDataB(MidB2B(b, 12, 16)),
            MDHM.SetDataB(MidB2B(b, 28, 8)),
            MidB2S(b, 36, 2),
            MidB2S(b, 38, 2),
            MidB2S(b, 40, 1),
            [ODDS_UMATAN_INFO.SetDataB(MidB2B(b, 41 + 13 * i, 13)) for i in range(306)],
            MidB2S(b, 4019, 11),
            MidB2S(b, 4030, 2),
        )
```
