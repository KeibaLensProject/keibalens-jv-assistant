# 104.騎手変更 (Python)

出典: `context/JVData_Struct.py` (JRA-VAN提供サンプル, 最終更新 2026-07-31, SDK Ver.5.0.0)

| クラス (`@dataclass`) | 概要 |
|---|---|
| `JC_INFO` | 変更情報 |
| `JV_JC_INFO` | 騎手変更 |

```python
@dataclass
class JC_INFO:
    """変更情報"""
    Futan: str      # 負担重量
    KisyuCode: str  # 騎手コード
    KisyuName: str  # 騎手名
    MinaraiCD: str  # 騎手見習コード

    # データセット
    @classmethod
    def SetDataB(cls, b):
        return cls(
            MidB2S(b, 1, 3),
            MidB2S(b, 4, 5),
            MidB2S(b, 9, 34),
            MidB2S(b, 43, 1),
        )

@dataclass
class JV_JC_INFO:
    head: RECORD_ID         # <レコードヘッダー>
    id: RACE_ID             # <競走識別情報>
    HappyoTime: MDHM        # 発表月日時分
    Umaban: str             # 馬番
    Bamei: str              # 馬名
    JCInfoAfter: JC_INFO    # <変更後情報>
    JCInfoBefore: JC_INFO   # <変更前情報>
    crlf: str               # レコード区切り

    # データセット
    @classmethod
    def SetDataB(cls, b):
        return cls(
            RECORD_ID.SetDataB(MidB2B(b, 1, 11)),
            RACE_ID.SetDataB(MidB2B(b, 12, 16)),
            MDHM.SetDataB(MidB2B(b, 28, 8)),
            MidB2S(b, 36, 2),
            MidB2S(b, 38, 36),
            JC_INFO.SetDataB(MidB2B(b, 74, 43)),
            JC_INFO.SetDataB(MidB2B(b, 117, 43)),
            MidB2S(b, 160, 2),
        )
```
