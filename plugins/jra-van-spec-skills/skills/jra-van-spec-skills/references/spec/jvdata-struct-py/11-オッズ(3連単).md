| クラス (`@dataclass`) | 概要 |
|---|---|
| `ODDS_SANRENTAN_INFO` | 3連単オッズ |
| `JV_O6_ODDS_SANRENTAN` | オッズ(3連単) |

```python
@dataclass
class ODDS_SANRENTAN_INFO:
    """3連単オッズ"""
    Kumi: str       # 組番
    Odds: str       # オッズ
    Ninki: str      # 人気順

    # データセット
    @classmethod
    def SetDataB(cls, b):
        return cls(
            MidB2S(b, 1, 6),
            MidB2S(b, 7, 7),
            MidB2S(b, 14, 4),
        )

@dataclass
class JV_O6_ODDS_SANRENTAN:
    head: RECORD_ID                                 # <レコードヘッダー>
    id: RACE_ID                                     # <競走識別情報>
    HappyoTime: MDHM                                # 発表月日時分
    TorokuTosu: str                                 # 登録頭数
    SyussoTosu: str                                 # 出走頭数
    SanrentanFlag: str                              # 発売フラグ 3連単
    OddsSanrentanInfo: List[ODDS_SANRENTAN_INFO]    # <3連単票数オッズ>
    TotalHyosuSanrentan: str                        # 3連単票数合計
    crlf: str                                       # レコード区切り

    # データセット
    @classmethod
    def SetDataB(cls, b):
        return cls(
            RECORD_ID.SetDataB(MidB2B(b, 1, 11)),
            RACE_ID.SetDataB(MidB2B(b, 12, 16)),
            MDHM.SetDataB(MidB2B(b, 28, 8)),
            MidB2S(b, 36, 2),
            MidB2S(b, 38, 2),
            MidB2S(b, 40, 1),
            [ODDS_SANRENTAN_INFO.SetDataB(MidB2B(b, 41 + 17 * i, 17)) for i in range(4896)],
            MidB2S(b, 83273, 11),
            MidB2S(b, 83284, 2),
        )
```
